# Blog REST API

## Запуск

Из папки проекта установите зависимости и запустите приложение:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe main.py
```

Сервер будет доступен по адресу `http://127.0.0.1:5000`.

Для запросов с телом указывайте заголовок `Content-Type: application/json`.

## Операции с постами

### Создать пост

`POST http://127.0.0.1:5000/tweet`

```json
{
  "body": "Первый пост в блоге",
  "author": "@ivan"
}
```

В ответе будет присвоенный посту `id`.

### Получить все посты

`GET http://127.0.0.1:5000/tweet`

### Получить один пост

`GET http://127.0.0.1:5000/tweet/1`

Замените `1` на ID нужного поста.

### Изменить пост

`PUT http://127.0.0.1:5000/tweet/1`

```json
{
  "body": "Обновлённый текст поста",
  "author": "@ivan"
}
```

### Удалить пост

`DELETE http://127.0.0.1:5000/tweet/1`

Замените `1` на ID нужного поста. Успешное удаление возвращает статус `204`.

Посты хранятся в памяти и очищаются при перезапуске приложения.
